LUMIVORE - FL STUDIO TROUBLESHOOTING

Plugin not listed after scanning
  - Confirm the folder exists:  C:\Program Files\Common Files\VST3\Lumivore.vst3\Contents\x86_64-win\Lumivore.vst3
    It must be the folder-style bundle, not a single renamed file.
  - Options -> Manage plugins: ensure the VST3 path above is listed, then run the scan again.
    If a previous scan flagged the plugin as failed, use the option to re-verify / rescan
    (verify plugins) so FL tries it again.
  - Look in Installed -> Effects (it is an effect, not an instrument).

Window is black / shows "Shader error"
  - A shader failed to compile on your GPU/driver. The overlay shows the driver's message;
    please send it. Update your graphics driver (NVIDIA/AMD/Intel). OpenGL 3.2+ is required.
  - Remote desktop sessions and some virtual machines expose only old OpenGL. Run locally.

Plugin loads but no motion
  - Confirm audio is actually reaching the insert (the mixer meter moves).
  - Raise Intensity and the Bass/Mids/Highs sliders.

Antivirus / SmartScreen blocks the file
  - The build is unsigned. Windows may warn on first run of install.bat. Code signing needs a
    paid certificate and is not included.

Crash on closing the editor
  - Please report with the Windows Event Viewer entry and your GPU model.

Reporting a problem, include: Windows build, FL Studio build, GPU + driver version, and what
happened when you opened the plugin window.
